## 2. CSAT 추정 모델 검증

학습에 쓰지 않은 리뷰 38건으로 평가했다 (학습 117건, 리뷰 이벤트 리뷰 제외). 모델: `csat-ridge-v0.1` (특징 13개 릿지 회귀).

| 모델 | 별점 예측 MAE (낮을수록 좋음) |
|---|---|
| 상수 기준선 (평균 별점) | 1.236 |
| Valence 하나만 쓰는 회귀 | 0.697 |
| **전체 특징 릿지 회귀** | **0.564** |

- Valence 단일 회귀 대비 MAE 19.1% 개선, 예측과 실제 별점의 Spearman ρ = 0.699
- 만족 비율(별점 4점 이상): 실제 68.4%, 추정 63.2% (보정 없이 추정 별점 4.0 이상으로 세면 55.3%). 회귀 예측은 평균 쪽으로 몰리기 때문에, 학습 데이터의 실제 만족 비율에 맞춰 기준값을 보정했다.
- 영향이 큰 특징 (표준화 계수): min_valence -0.71, last_valence +0.59, peak_end -0.58, frustration +0.28, churn -0.28. 특징끼리 상관이 높아서(예: 최저·평균 Valence, Peak-End) 개별 계수의 부호는 해석하지 않는다.

- 상담·영상에는 리뷰로 학습한 모델을 그대로 적용했다. 말투와 길이가 달라서 오차가 더 클 수 있고, 상담 데이터로 따로 검증해야 한다.

### 좌절 지수 (채널 내 z-score)

| 브랜드 | 상담 | 리뷰 |
|---|---|---|
| 배달앱 | +0.00 | - |
| 치킨브랜드A | - | -0.03 |
| 피자브랜드B | - | +0.03 |

0은 그 채널의 평균, +1은 채널 안에서 1 표준편차 위다. 같은 브랜드가 여러 채널에 있을 때, 채널 편향을 빼고 위치를 비교할 수 있다. 세션 3개 미만인 칸과 그런 칸만 있는 브랜드는 뺐다.

## 5. 해석할 때 주의할 점

- 채널마다 브랜드 구성이 다르면, 채널 차이처럼 보이는 것이 실제로는 브랜드 차이일 수 있다. 채널별 브랜드 구성:
  - 상담 / 배달앱: 4건
  - 리뷰 / 치킨브랜드A: 90건
  - 리뷰 / 피자브랜드B: 90건
  - 영상(크리에이터) / 치킨브랜드A: 1건
- 감정·불만 분류는 사전·규칙 기반 기준선이다. 파인튜닝 모델로 바꾸면 구성비가 달라질 수 있다.
- 이탈·추천 의사는 표현된 경우만 잡는다. 실제 행동(재구매, 이탈)과 다를 수 있다.
