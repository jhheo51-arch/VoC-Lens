## 1. 배경

- 기업의 VoC는 대부분 **텍스트**(설문, 리뷰, 상담 기록) 중심으로 분석된다. 하지만 상담 음성과 영상 속 목소리에는 텍스트로 옮기면 사라지는 감정 정보(톤, 속도, 떨림, 한숨)가 담겨 있다.
- 설문 응답률은 낮다. 그래서 응답하지 않는 다수 고객의 감정은 리뷰, 상담 녹취, SNS 영상 같은 **자발적 VoC**에서 찾아야 한다.
- 국내 CX/VoC 분석 직무 공고(예: 이노션 CX/VoC 데이터 분석가)는 다음을 공통으로 요구한다.
  - 다양한 고객 접점(콜센터, 챗봇, 이메일 등)의 비정형 VoC 분석과 인사이트 발굴
  - VoC 분류 기준(taxonomy)과 분석 기준 수립
  - AI 기반 분석·자동화 체계 기획
  - 주요 이슈 모니터링, 대시보드·리포트
  - NPS·CSAT·CES 같은 CX 지표 이해, SQL·Python

**VoC Lens**는 세 가지 고객 접점 데이터를 하나의 감정 지수 체계로 분석한다.
- **영상**: YouTube 리뷰, 인터뷰, 브이로그 등
- **상담 음성**: 콜센터·고객 응대 녹취
- **리뷰 텍스트**: 배달앱, 쇼핑몰, 앱스토어 후기 등

분석 결과는 **CX 인사이트와 우선순위가 매겨진 개선 과제**로 연결된다.

## 2. 문제 정의

| 문제 | 현재 상황 | VoC Lens의 해결 |
|---|---|---|
| 채널별 분석 단절 | 리뷰, 상담, SNS 영상을 따로 분석해 같은 이슈를 연결하지 못함 | 3개 채널을 같은 지수 체계와 분류 기준으로 통합 |
| 감정 정보 손실 | 음성을 STT로 텍스트화하면 톤·속도·떨림 정보가 사라짐 | 음향 특징과 텍스트를 함께 분석 |
| 분석 비용 | 긴 상담·영상, 대량 리뷰를 사람이 직접 읽고 정리해야 함 | 업로드·URL 입력만으로 자동 분석 |
| 인사이트 단절 | 감정 점수가 나와도 "그래서 무엇을 개선할지"로 이어지지 않음 | 페인 포인트 → 근거 → 개선 과제 → 우선순위 자동 도출 |
| 기준 부재 | 감정·불만 유형 분류 기준이 조직마다 제각각 | 문서화된 감정·불만 분류 기준 제공 |

## 3. 목표와 비목표

### 목표 (Goals)
1. 영상, 상담 음성, 리뷰 텍스트 3종을 입력받아 **6개 감정·CX 지수**를 산출한다.
2. 처리 속도 목표:
   - 5분 분량 영상·음성: 10분 이내 (CPU 기준)
   - 리뷰 1,000건: 5분 이내
3. 감정 지수를 **CX 관점(불만 유형, 고객 여정 단계, 추정 CSAT·CES)** 으로 재해석해 보여준다.
4. **채널 간 비교**를 제공한다 (예: 같은 브랜드의 리뷰 vs 상담 vs YouTube 반응).
5. 분석 결과로 **우선순위가 매겨진 개선 과제 리포트**(기획 산출물)를 자동 생성한다.
6. 공개 한국어 감정 데이터셋으로 성능을 **정량 검증**하고 결과를 공개한다.

### 비목표 (Non-goals)
- 의료적 진단을 하지 않는다. "우울"은 **부정 정서(저활력) 지수**로 표현하며 임상 지표가 아님을 명시한다.
- 특정 개인을 식별하거나 개인 단위로 평가하지 않는다.
- 이미지·얼굴 표정 분석은 하지 않는다 (v0.2에서 제외).
- 한국어 외 언어는 지원하지 않는다.
- 배달앱·쇼핑몰을 자동 크롤링하지 않는다. 리뷰는 사용자가 CSV로 올리거나 공개 데이터셋을 쓴다 (11장 참조).
- 실시간 스트리밍 분석은 범위 밖이다.
- 감정 모델을 처음부터 학습하지 않는다. 사전학습 모델을 활용하고 필요하면 파인튜닝한다.

## 4. 사용자 (페르소나)

| 페르소나 | 니즈 | 주요 사용 기능 |
|---|---|---|
| **CX 데이터 분석가** | 채널별 비정형 VoC에서 감정 패턴과 이슈를 빠르게 찾고 싶다 | 타임라인, 리뷰 집계, 채널 비교, SQL 집계, 데이터 내보내기 |
| **CX 기획자/매니저** | 어느 접점에서 고객이 불편한지, 무엇부터 고칠지 알고 싶다 | 고객 여정 히트맵, 개선 과제 리포트 |
| **상담 품질 관리자 (QA)** | 어떤 상담에서 고객이 화났고, 응대 후 풀렸는지 알고 싶다 | 감정 회복 지수, 좌절 지수, 상담별 이벤트 |
| **채용 담당자 (포트폴리오 열람자)** | 지원자의 분석력, 기획력, 구현력을 한눈에 보고 싶다 | 데모 대시보드, 케이스 스터디 리포트 |

## 5. 사용자 스토리

**영상**
- 분석가로서, YouTube URL을 붙여넣으면 감정 변화를 시간축으로 보고 싶다.
- 분석가로서, 스트레스가 급등한 구간에서 어떤 말이 나왔는지 바로 확인하고 싶다.

**상담 음성**
- QA 관리자로서, 상담 녹취를 올리면 고객과 상담원을 구분해 고객 감정만 따로 보고 싶다.
- QA 관리자로서, 고객이 화났다가 응대 후 진정됐는지(감정 회복)를 상담별로 비교하고 싶다.

**리뷰 텍스트**
- 분석가로서, 배달앱 리뷰 CSV를 올리면 불만 유형별 빈도와 대표 리뷰를 보고 싶다.
- 분석가로서, 별점과 감정 지수가 어긋나는 리뷰(예: 별점 5점인데 불만 내용)를 찾고 싶다.

**통합·기획**
- 분석가로서, 같은 브랜드의 리뷰, 상담, 영상 반응을 같은 기준으로 비교하고 싶다.
- 기획자로서, 감정 데이터를 고객 여정 단계(탐색→주문→배송·이용→문의→재구매)에 매핑해 페인 포인트를 보고 싶다.
- 기획자로서, 개선 과제를 영향도·빈도·실행 난이도 기준으로 우선순위화한 리포트를 받고 싶다.

## 6. 기능 요구사항

우선순위: **P0** = MVP 필수 / **P1** = 포트폴리오 완성도 / **P2** = 확장

### 6.1 입력 처리
| ID | 기능 | 우선순위 |
|---|---|---|
| F-01 | **영상**: YouTube URL 입력 → 오디오 추출 (종류 제한 없음) | P0 |
| F-02 | **상담 음성**: 오디오 파일 업로드 (WAV/MP3/M4A) | P0 |
| F-03 | **리뷰 텍스트**: CSV 업로드 (필수 열: 리뷰 본문 / 선택 열: 별점, 작성일, 매장·상품, 사장님 답글) 또는 직접 붙여넣기 | P0 |
| F-04 | 영상·음성 길이 제한 (기본 20분), 구간 지정 분석 | P1 |
| F-05 | 여러 URL·파일 일괄 분석 (배치) | P1 |
| F-06 | YouTube 영상 **댓글 수집** (YouTube Data API) → 리뷰 파이프라인으로 분석. "3:20" 같은 **타임스탬프 댓글을 영상 타임라인에 연결**, 크리에이터 감정 vs 시청자 감정 비교 | P1 |
| F-07 | 데이터 출처 태깅 (브랜드, 채널, 카테고리) → 채널 간 비교에 사용 | P0 |

| ID | 기능 | 우선순위 |
|---|---|---|
| F-10 | 음성 구간 검출(VAD), SNR 측정, 배경음악 분리(영상, Colab 옵션) | P0 |

| F-12 | 한국어 STT + 단어 타임스탬프 + 발화별 STT 신뢰도. 영상은 사람이 단 자막을 우선 사용 | P0 |
| F-13 | **음향 감정 분석**: eGeMAPS 특징 + 사전학습 음성 감정 임베딩, **화자 기준 정규화** | P0 |

### 6.4 융합과 지수 산출 (7장 참조)
| ID | 기능 | 우선순위 |
|---|---|---|
| F-30 | 음향 + 텍스트 **융합**: 각성은 음향 중심, 긍정·부정은 텍스트 중심. 신뢰도(STT·SNR)에 따라 가중치 동적 조정 | P0 |
| F-31 | **6개 지수** 산출 (0–100 원점수 + 채널별 기준 대비 백분위) | P0 |
| F-32 | 신뢰도(STT·음향·텍스트·융합)와 근거 발화·문장 표시, 저신뢰 단위는 집계 가중치 축소 | P1 |
| F-33 | 감정 급변 구간(이벤트) 자동 탐지 (평활화 + 변화점 탐지) | P0 |
| F-35 | 세션 단위 **Peak-End 점수**: 평균 외에 최고점·임계치 초과 시간·종료 시점 값 | P1 |
| F-34 | 반어·비꼼처럼 음향과 텍스트가 어긋나는 구간 탐지 | P2 |

### 6.5 CX 해석 레이어 (분석가 + 기획 역량)
| ID | 기능 | 우선순위 |
|---|---|---|
| F-40 | 페인 포인트 Top N + 대표 원문(클러스터 중심 3개 + 최고 강도 1개) | P0 |
| F-41 | 고객 여정 단계 태깅 → **여정 단계 × 감정 히트맵** (칸마다 표본 수·신뢰구간, n<30 흐리게) | P1 |
| F-42 | **추정 CSAT / CES / NPS 성향**: CSAT는 별점을 대리 정답으로 학습해 상담·영상에 적용, CES는 좌절·반복·대기 신호로 산출, NPS는 추천·이탈 의사로 분류 | P1 |
| F-43 | **채널 간 비교**: 원점수가 아닌 채널 내 표준화 지수와 불만 유형 구성비로 비교, "조용한 불만"(상담엔 많고 리뷰엔 없는 이슈) 탐지 | P1 |
| F-44 | **개선 과제 리포트 (LLM 없이)**: 우선순위 점수(빈도×강도×추세×비즈니스 영향) + 난이도 표 → 4분면 매트릭스, 템플릿 문장, 근거 원문 | P1 |
| F-46 | **회복 계기 분석**: 고객 감정이 회복된 시점 직전의 상담원 발화를 모아 효과적인 응대 표현 도출 | P1 |
| F-47 | 집계 통계: 소표본 보정(베이지안 축소), 부트스트랩 신뢰구간, 그룹 간 차이 검정과 효과 크기 | P1 |
| F-45 | 기간별 추이, 급증 이슈 알림 (이동평균 ± 3σ, 변화점) | P2 |

### 6.6 VoC 분류 기준 (초안)
| 대분류 | 소분류 예시 |
|---|---|
| 제품·품질 | 맛, 양, 신선도, 불량, 포장 상태 |
| 배송·이행 | 지연, 오배송, 누락, 배달원 응대 |
| 가격·혜택 | 가격, 배달비, 쿠폰·할인, 환불 |
| 응대·서비스 | 상담 태도, 대기 시간, 해결 여부, 사장님 답글 |
| 사용성 | 앱 오류, 결제 문제, 정보 부족 |
| 기타 | 칭찬, 제안, 분류 불가 |

## 7. 지수 정의

심리학의 **Valence(긍정–부정) × Arousal(각성 수준)** 2차원 모델을 기본으로 한다. 지수는 두 그룹으로 나뉜다.
- **감정 상태 지수**: 기본 3개
- **CX 행동 지수**: 추가 3개

산식은 공개하고, 가중치는 검증 데이터로 보정한다.

### 7.1 감정 상태 지수

| 지수 | 의미 | 음성 신호 | 텍스트 신호 |
|---|---|---|---|
| **① 스트레스** | 부정적이면서 각성이 높은 상태 (긴장, 짜증, 분노) | 피치 상승·변동 증가, 에너지 증가, 말 속도 증가 | 분노·짜증 표현, 강한 부정어, 느낌표·욕설 |
| **② 행복** | 긍정적인 상태 (만족, 기쁨) | 밝은 톤(피치 범위 넓음), 웃음 | 칭찬, 만족 표현, 긍정 이모티콘 |
| **③ 부정 정서(저활력)** | 부정적이면서 각성이 낮은 상태 (실망, 체념, 무기력) | 낮은 에너지, 단조로운 피치, 긴 휴지, 느린 말 속도 | 실망·체념 표현 ("그냥 그래요", "다신 안 시킴") |

### 7.2 CX 행동 지수

| 지수 | 의미 | 음성 신호 | 텍스트 신호 | 연결 CX 지표 |
|---|---|---|---|---|
| **④ 좌절(고객 노력)** | 고객이 문제를 해결하느라 애쓰는 정도 | 한숨, 말 끊기, 같은 말 반복, 말 속도 급변 | "몇 번째", "또", "계속", "연락이 안 돼서", 반복 문의 언급 | **CES** |
| **⑤ 감정 회복** | 부정 감정이 대화·경험 뒤에 긍정으로 돌아섰는지 | 앞 구간 대비 뒤 구간의 감정 변화량, 회복까지 걸린 시간 | 리뷰 내 흐름 ("처음엔 화났는데 사장님이 바로 다시 보내주셔서…"), 사장님 답글 전후 | **서비스 회복**, FCR |
| **⑥ 몰입/관심** | 제품·서비스에 대한 관심과 열의 | 발화량, 에너지 변화폭, 질문 빈도 | 리뷰 길이·구체성, 재구매·추천 의사 표현 | 재구매 의향, **NPS 성향** |

### 7.3 입력별 적용 범위

| 지수 | 영상 | 상담 음성 | 리뷰 텍스트 |
|---|:---:|:---:|:---:|
| ① 스트레스 | ● | ● | ● (텍스트만) |
| ② 행복 | ● | ● | ● (텍스트만) |
| ③ 부정 정서 | ● | ● | ● (텍스트만) |
| ④ 좌절 | ● | ● (가장 정확) | ◐ (언어 표현만) |
| ⑤ 감정 회복 | ● | ● (가장 정확) | ◐ (리뷰 내 흐름, 답글 전후) |
| ⑥ 몰입 | ● | ◐ | ● |

● 음성+텍스트 융합 / ◐ 일부 신호만 사용 (신뢰도 낮음으로 표시)

### 7.4 산식

```
[감정 상태 지수 ①②③, 좌절 ④, 몰입 ⑥]
지수 = 100 × clip( w_a × 음향점수 + w_t × 텍스트점수 , 0, 1 )
 - 리뷰 텍스트: w_a = 0, w_t = 1
 - 영상·상담: 초기값 w_a = 0.5, w_t = 0.5 → 검증셋으로 보정

[감정 회복 ⑤]
회복 = 50 + 50 × clip( (후반부 Valence − 전반부 Valence) / 정규화 상수 , −1, 1 )
 - 50 = 변화 없음, 100 = 완전 회복, 0 = 악화
 - 전반부에 부정 감정이 일정 수준 이상 있을 때만 산출 (아니면 "해당 없음")
 - 상담: 고객 화자 발화만 사용
```

> 고지: 모든 지수는 **추정치**이며 의료적 진단이나 개인 평가에 쓸 수 없다. 이 문구를 UI와 리포트에 항상 표시한다.

## 8. 기술 구성 (초안)

### 8.1 실행 환경
- 개발 PC: Intel Iris Xe 내장 그래픽, RAM 16GB, **NVIDIA GPU 없음**
- **확정**: 개발·추론·시연은 **CPU**에서 한다. 모델 파인튜닝, 대량 검증 실험, Demucs·Whisper large-v3는 **Google Colab(무료 T4 GPU)** 에서 돌린다.

## 11. 윤리·법적 고려사항

- **리뷰 데이터**:
  - 배달앱·쇼핑몰은 이용약관으로 자동 수집(크롤링)을 제한하는 경우가 많다. 그래서 공개 데이터셋, 사용자가 정당하게 확보한 CSV, 공식 API(YouTube Data API)만 사용한다.
  - 작성자 닉네임 등 개인정보는 수집 단계에서 제거한다.
- **상담 음성**:
  - 공개 데이터셋(AI Hub 등)이나 직접 녹음한 재연 음성만 쓴다.
  - 실제 고객 녹취를 쓰려면 개인정보보호법상 동의가 필요하다. 전화번호·주소 등 개인정보 발화는 마스킹한다.
- **영상**:
  - 공개 영상만 분석한다. 원본 오디오는 분석 후 삭제하고 파생 데이터(지수, 발화 요약)만 보관한다.
  - YouTube 이용약관을 확인하고 비상업·연구 목적으로 한정한다.
- **오용 방지**:
  - 채용 평가, 직원 감시, 개인 진단 용도로 쓰지 못하게 고지한다.
  - 감정 인식 AI는 국가별 규제를 받는다는 점을 문서에 명시한다 (예: EU AI Act는 직장·교육 내 감정 인식을 금지한다).
  - 상담원 개인 평가가 아니라 **상담 프로세스 개선**에 쓰도록 리포트를 설계한다.
- **편향**: 성별·연령대, 사투리 여부별 성능 차이를 측정해 공개한다.
